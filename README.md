# Scene Puppet

Приложение для создания анимированных сцен в реальном времени с записью,
воспроизведением и экспортом в видео. Один пользователь, без сети.

## Что это

Запись — это **список действий (event log)**, а не видеопоток.
Воспроизведение — проигрывание списка, экспорт — рендер в MP4.
И интерактивный экран, и Play, и Export используют один и тот же рендер,
поэтому результат всегда совпадает.

## Установка

```powershell
pip install -r requirements.txt
```

Требования:
- Python 3.10+ (проверено на 3.13)
- `pygame-ce`, `sounddevice`, `numpy`, `Pillow`
- **ffmpeg** в `PATH` (нужен только для экспорта видео)
- Микрофон (опционально; при отсутствии запись идёт без голоса)

## Запуск

```powershell
python main.py
```

## Интерфейс

Верхняя панель:
- **Record** — начать запись; во время записи кнопка меняется на
  **Stop Recording**
- **Pause** — пауза во время записи (кнопка меняется на *Resume*). Во время
  паузы доступны только **Stop Recording** и **Resume**, остальные кнопки
  неактивны. Анимация перехода при создании сцены **не** проигрывается — она
  воспроизводится только при **Play** (из записанного события паузы).
- **Play** — воспроизвести запись; во время воспроизведения кнопка меняется
  на **Stop playing** (повторное нажатие останавливает проигрывание), а
  остальные кнопки на панели недоступны. В строке статуса при этом
  отображается текущее время воспроизведения в виде
  `t=<текущая>/<общая>s`
- **Export** — отрендерить MP4
- **Save / Load** — сохранить/открыть проект
- **+ Sprite / + Sound / + Background** — добавить свой ассет: выбранный
  файл копируется в соответствующую папку (`assets/sprites`,
  `assets/sounds`, `assets/backgrounds`) и сразу появляется в панели
- **Panels** — показать/скрыть правую панель

Все файлы из папок `assets/sprites`, `assets/sounds` и
`assets/backgrounds` **автоматически загружаются при запуске**, поэтому
добавленные ранее ассеты доступны в панелях без повторного импорта.

Правая панель — вкладки **Sprites**, **Sounds**, **Backgrounds**, **Scenes**.
Спрайты перетаскиваются из панели прямо на сцену (drag & drop).
Звук играет по клику; во время записи момент нажатия фиксируется в журнале.
Клик по фону переключает фон; клик по сцене — переключает активную сцену.

Сцена имеет **кадр** (видимая область, обведён белым) и **буферную зону**
вокруг него. Объекты за кадром существуют, но не видны зрителю.

## Сценарий работы

1. Соберите сцену вручную: перетащите спрайты, выберите фон.
2. Нажмите **Record**.
3. Двигайте спрайты мышью, включайте звуки, говорите в микрофон.
4. **Pause** — запись приостанавливается без анимации: объекты можно
   переставить (они телепортируются), сменить фон или сцену. Кнопка
   **Pause** при этом меняется на **Resume**, а прочие кнопки недоступны.
   Снятие паузы кнопкой **Resume** продолжает запись.
5. **Stop Recording** — остановить запись.
6. **Play** — просмотреть результат.
7. **Export** — сохранить видеофайл MP4.

Выбранный спрайт (клик по нему) обводится рамкой с квадратными **маркерами
на серединах граней**. Потяните маркер — спрайт масштабируется по этой оси
(независимо по X и Y) с закреплением **противоположной** грани. Масштаб и
закреплённая грань записываются в журнал действий, поэтому при
воспроизведении/экспорте закреплённая сторона остаётся неподвижной.

Удалить выбранный спрайт — клавиша **Delete**. Выход — **Esc**.

**Навигация по виду:** зажмите **среднюю кнопку мыши** (колёсико) и тяните —
вид сцены панорамируется. **Ctrl + колёсико** — масштаб (zoom) относительно
курсора; **колёсико** без Ctrl меняет порядок наложения (z-order) выбранного
спрайта.

## Формат проекта

Проект — папка с `project.json` (сцены, ассеты, event log) и копиями
используемых ассетов и дорожки микрофона (`mic.wav`).

Структура event log (пример):

```json
{
  "duration": 45.2,
  "events": [
    {"t": 0.0,   "type": "move",       "sprite": "hero", "x": 100, "y": 200},
    {"t": 1.2,   "type": "sound",      "sound": "laugh"},
    {"t": 5.0,   "type": "pause",      "transition": "curtain",
                 "duration": 0.8, "scene": "scene2"},
    {"t": 5.0,   "type": "scene_change","scene": "scene2"},
    {"t": 6.5,   "type": "move",       "sprite": "villain", "x": 300, "y": 150}
  ]
}
```

Движение хранится как последовательность ключевых точек и линейно
интерполируется при воспроизведении и экспорте.
